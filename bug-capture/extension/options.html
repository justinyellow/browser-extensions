Bug Capture Settings

Claude
GitHub

Needs: Issues (write) and Contents (write) on the mapped repos, plus Projects (write) if you set project numbers. A classic token with repo + project scopes also works.

One per line: host owner/repo [project number] [service="App"] [dir="frontend"] [labels="stack: app"]. Subdomains of the host match too; prefix with = for that host only. Add :port or /path to narrow it (localhost:3000, api.example.com/v1). The most specific line wins. Lines starting with # are ignored. service prefixes the issue title and tells Claude where the code lives; labels are added to the issue. A blank template lives in the repo as configs/bug-capture.example.json.

Config file

Import a JSON file with keys and mappings, or export the current settings to another machine. The file can contain secrets — do not commit it.
