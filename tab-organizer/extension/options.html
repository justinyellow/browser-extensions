Tab Organizer Settings

Saved tabs go to Other bookmarks › Tab Organizer › (group name). Everything closed is listed in the popup and can be reopened.

Obsidian

One folder per line. Notes outside these folders are ignored. Default is PARA: Inbox, Areas, Projects, Resources.

Config file

Import a JSON file with keys and settings, or export the current ones to another machine. The file can contain secrets — do not commit it.
