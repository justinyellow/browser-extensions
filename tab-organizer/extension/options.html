Tab Organizer Settings

A tab left ungrouped can join a group that formed later. Only windows you've used since the last re-check are looked at, so idle windows cost nothing.

Saved tabs go to Other bookmarks › Tab Organizer › (group name). Everything closed is listed in the popup and can be reopened.

Obsidian (optional)

Off by default. Enable this only if you use Obsidian with the Local REST API plugin. Otherwise kept tabs are saved as Chrome bookmarks.

One folder per line. Notes outside these folders are ignored. Default is PARA: Inbox, Areas, Projects, Resources.

Chrome cannot nest groups, so groups from the same company or project share a colour instead of a name prefix — names stay short ("Code Review", "Payroll"). Standing tools you keep open across every project (calendar, meetings, email, HR, expenses) are grouped by what they are for rather than left loose. After changing this, use Regroup everything in the popup.

Added to the grouping prompt and applied ahead of the built-in rules, so these win wherever they disagree. While this box has anything in it, group names are used exactly as Claude returns them — the automatic trim of a "Company · Name" prefix steps aside, so you can ask for prefixes here if you actually want them.

Background that also applies to stale-tab cleanup, Obsidian notes, and the daily digest — not just grouping.

Tabs are only grouped when they are about the same workstream, so one-off tabs are left ungrouped on purpose. Name the groups you want above, or the ones you never want.

Config file

Import a JSON file with keys and settings, or export the current ones to another machine. The file can contain secrets — do not commit it.
